Features
Everything you need. Nothing you don't.
⚡
Selective Streaming
Stream any song directly by byte offset. Only that song loads — device RAM stays near zero regardless of playlist size.
🔒
AES-256-GCM Encryption
Encrypt individual songs or the entire container. PBKDF2-SHA256 key derivation with 100,000 iterations. Zero external crypto deps.
🛡️
Reed-Solomon ECC
RS(255,223) error correction per song unit. Corrupt bytes are automatically recovered on read — corruption chances near zero.
📊
Rich Metadata
BPM, musical key, mood tags, synced LRC lyrics, chapter markers, waveform preview, acoustic fingerprint — all embedded.
🌐
HTTP Range Streaming
Host a .oucs file on any CDN. Stream individual songs via HTTP Range requests — no full download, no server code needed.
🔌
Plugin / Hook System
Intercept pack, chunk-read, extract, and error events. Add custom processing — equalizer, analytics, normalization — without touching core.
🔄
Merge & Split
Combine multiple .oucs playlists into one or split them — without re-encoding a single byte of audio.
🔍
Deduplication
Same song added twice? Engine detects via CRC-32 fingerprint match and stores it once, referenced multiple times.
🌍
Multi-language Bindings
C core → Python (pip install oucs) → JavaScript WASM (npm install oucs-engine) → Java JNI (Android + Desktop). Zero runtime deps.

Code Examples
Works everywhere
from oucs import OucsFile

# Pack songs into .oucs
with OucsFile.create("playlist.oucs") as f:
    f.set_meta(theme="Summer Hits", description="Best tracks")
    f.add_song("track1.mp3", name="Track One")
    f.add_song("track2.flac", name="Track Two", password="secret")
    f.save()

# Stream song 0 — only that song loads (device load = near zero)
with OucsFile.open("playlist.oucs") as f:
    with f.stream(0, chunk_size=4096) as stream:
        for chunk in stream:
            audio_player.feed(chunk)

# URL streaming — no full download
with OucsFile.open_url("https://cdn.example.com/playlist.oucs") as f:
    for chunk in f.stream(0):
        player.feed(chunk)
const { OucsFile, loadModule } = require('oucs-engine');

await loadModule();

// Pack songs
const f = await OucsFile.open('playlist.oucs');
console.log(f.songCount + ' songs');

// Stream song 0 chunk-by-chunk
const stream = await f.stream(0, 4096);
for await (const chunk of stream) {
    audioPlayer.feed(chunk);
}
f.close();

// Install: npm install oucs-engine
// Load native library
OucsEngine.loadLibrary();

// Write
try (OucsWriter w = OucsEngine.create("playlist.oucs")) {
    w.setMeta("My Playlist", "Best tracks", null, "");
    w.addSong("song1.mp3", "Song One", "");
    w.save();
}

// Read & stream
try (OucsReader r = OucsEngine.open("playlist.oucs")) {
    try (OucsStream s = r.stream(0, 4096)) {
        byte[] chunk;
        while ((chunk = s.readChunk()) != null) {
            audioPlayer.feed(chunk);
        }
    }
}
// Pack songs into .oucs
OucsWriter *w = oucs_writer_create("playlist.oucs", 0);
oucs_writer_add_song(w, "track1.mp3", "Track One", "", NULL);
oucs_writer_add_song(w, "track2.wav", "Track Two", "", NULL);
oucs_writer_finalize(w);
oucs_writer_free(w);

// Stream song 1 — chunk-by-chunk
OucsReader *r = oucs_reader_open("playlist.oucs");
OucsStream *s = oucs_stream_open(r, 1, 4096, NULL);

uint8_t buf[4096]; size_t n;
while (oucs_stream_read_chunk(s, buf, sizeof(buf), &n) == OUCS_OK && n > 0) {
    audio_player_feed(buf, n);
}
oucs_stream_free(s);
oucs_reader_free(r);
Install
One line to get started

🐍 Python

pip install oucs
Requires liboucs built locally. See README.

🟨 JavaScript

npm install oucs-engine
Node.js + Browser (WASM). Zero deps.

☕ Java / Android

io.oucs:oucs:1.0.0
Maven / Gradle. JNI bindings included.

⚙️ C / C++

git clone github.com/ParthHariom/oucs
Build with cc or CMake. Zero deps, pure C11.
